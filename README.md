# Apple Sales Analysis Dashboard

## Project Overview
Interactive Excel dashboard for analyzing Apple sales data using
PostgreSQL, ODBC, Power Query, Power Pivot and DAX.

## Dashboard
[dashboard screenshot]

## Key KPIs
- Total Units Sold: 1.19M
- Total Transactions: 1.04M
- Total Revenue: $992.75M
- Warranty Claims: 30.84K

## Dashboard Features
- Units Sold by Country
- Top 10 Stores by Units Sold
- Sales Trend by Year
- Units Sold by Category
- Country, Category and Year slicers
- Dynamic KPI cards

## Data Model
Tables:
- Sales
- Products
- Stores
- Category
- Warranty

## Tools Used
- Microsoft Excel
- Power Query
- Power Pivot
- DAX
- PostgreSQL
- ODBC

## Data Modeling
Relationships were created between sales, products, stores,
categories and warranty data to enable cross-table analysis.
